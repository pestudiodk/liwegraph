# Security policy

Please do not report security vulnerabilities in public issues or pull
requests.

Until a dedicated security contact is published, use GitHub's private
security advisory form:

<https://github.com/pestudiodk/liwegraph/security/advisories/new>

Please include the affected version, impact, reproduction steps, and any
suggested mitigation. The project is not currently accepting general external
contributions; security reports are handled separately and privately.
