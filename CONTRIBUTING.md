# Contributing

LIWE Graph is not accepting external contributions at this time.

Please do not open pull requests, feature requests, documentation changes, or
public issues for the project yet. The repository is being kept closed while
the first public npm release is established. This policy will be updated when
an external contribution process is available.

Please report security vulnerabilities privately as described in
[`SECURITY.md`](SECURITY.md), not in a public issue.
